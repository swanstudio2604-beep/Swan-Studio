⚡ Server Hosting & Free Tier Cold-Start Note

Swan Studio is hosted on Render. On Render's Free tier, the web service automatically spins down when inactive for 15 minutes. The very first page load can take 30–50 seconds while the server wakes up.

Recommended Fixes for Bhumika:
  • Free Uptime Ping (Zero Cost): Set up a free monitor on UptimeRobot.com or cron-job.org pinging https://swan-studio.onrender.com/health every 10 minutes. This keeps the server permanently awake for 100% free!
  • Render Starter Tier ($7/mo): Upgrading to a paid Render instance keeps the server always-on with zero cold starts.
